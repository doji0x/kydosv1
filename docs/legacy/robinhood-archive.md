# Deprecated Robinhood implementation

The former Robinhood-chain launchpad implementation is preserved under `archive/` for historical reference only.

It is not built, routed, indexed, deployed, or documented as an active Kydos target. Do not import archived modules into active Solana code. Any useful ideas must be reimplemented against Solana account semantics, Anchor validation, Phantom signing, and Helius indexing rather than copied across unchanged.
